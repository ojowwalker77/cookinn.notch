# Changelog

All notable changes to cookinn.notch will be documented in this file.

## [2026.03.26]

Real-time Claude Code companion for macOS. Shows what Claude is doing near the MacBook notch.

- HTTP hooks for direct event delivery — no shell scripts, no jq
- Team badge showing active teammate count
- Context compaction display
- Session tracking with CwdChanged support
- Ralph loop detection (OpenCode + Claude Code)
- Alert mode with escalating sounds
- Multi-display support
- Semantic visual language with thermal color spectrum
