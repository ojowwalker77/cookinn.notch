# Research: Apple TTS APIs (AVSpeechSynthesizer)

> Generated by Matrix Deep Research on 2026-01-20
> Depth: standard

## Summary

Apple provides `AVSpeechSynthesizer` as the modern TTS API, replacing the older `say` command approach. It supports SSML markup, Personal Voice (iOS 17+/macOS 14+), pause/resume, and works natively with Swift. For macOS apps, this is significantly better than shelling out to `/usr/bin/say`.

## Key Findings

### AVSpeechSynthesizer Basics

The core API uses three classes:
- `AVSpeechSynthesizer` - the engine that speaks
- `AVSpeechUtterance` - what to speak (text + configuration)
- `AVSpeechSynthesisVoice` - which voice to use

```swift
import AVFoundation

let synthesizer = AVSpeechSynthesizer()
let utterance = AVSpeechUtterance(string: "Hello world")
utterance.voice = AVSpeechSynthesisVoice(language: "en-AU")  // Karen
utterance.rate = 0.5
utterance.pitchMultiplier = 1.0
synthesizer.speak(utterance)
```

### Control Methods

```swift
synthesizer.pauseSpeaking(at: .word)     // or .immediate
synthesizer.continueSpeaking()
synthesizer.stopSpeaking(at: .immediate) // or .word
synthesizer.isSpeaking  // Bool
synthesizer.isPaused    // Bool
```

### SSML Support

AVSpeechUtterance supports SSML for fine-grained control:

```swift
let ssml = """
<speak>
    Hello
    <break time="1s"/>
    <prosody rate="150%">This is faster</prosody>
    <break time="500ms"/>
    <prosody pitch="+10%">This is higher pitched</prosody>
</speak>
"""

if let utterance = AVSpeechUtterance(ssmlRepresentation: ssml) {
    synthesizer.speak(utterance)
}
```

Supported SSML tags:
- `<speak>` - root element (required)
- `<break time="Xs"/>` - pause (seconds or milliseconds)
- `<prosody rate="X%" pitch="X%">` - modify speed/pitch

### Voice Selection

```swift
// By language (returns default for that locale)
let voice = AVSpeechSynthesisVoice(language: "en-AU")  // Karen

// By identifier (for specific voice)
let voice = AVSpeechSynthesisVoice(identifier: "com.apple.ttsbundle.Karen-compact")

// Enhanced voice (if downloaded)
let voice = AVSpeechSynthesisVoice(identifier: "com.apple.voice.enhanced.en-AU.Karen")

// List all voices
for voice in AVSpeechSynthesisVoice.speechVoices() {
    print("\(voice.name) - \(voice.identifier) - \(voice.language)")
}

// Find specific voice by name
let karen = AVSpeechSynthesisVoice.speechVoices().first { $0.name == "Karen" }
```

**Voice identifier patterns:**
- Default: `com.apple.ttsbundle.[Name]-compact`
- Enhanced: `com.apple.voice.enhanced.[locale].[Name]`
- Premium: `com.apple.voice.premium.[locale].[Name]`

### Personal Voice (iOS 17+, macOS 14+)

Users can create a voice that sounds like them. Apps must request authorization:

```swift
// Request authorization
AVSpeechSynthesizer.requestPersonalVoiceAuthorization { status in
    switch status {
    case .authorized:
        // Can use personal voices
        let personalVoices = AVSpeechSynthesisVoice.speechVoices()
            .filter { $0.voiceTraits.contains(.isPersonalVoice) }
    case .denied, .notDetermined, .unsupported:
        // Fall back to system voices
        break
    @unknown default:
        break
    }
}

// Check current status
let status = AVSpeechSynthesizer.personalVoiceAuthorizationStatus

// Use personal voice
if let personalVoice = personalVoices.first {
    utterance.voice = personalVoice
}
```

## Best Practices

- **Keep synthesizer alive**: Store as instance property, not local variable
- **Use language codes**: `en-AU` for Karen instead of searching by name
- **Handle voice not found**: Fall back to default if specific voice unavailable
- **Respect audio session**: On iOS, configure audio session for playback
- **Use delegate**: Track completion for UI updates
- **Enhanced voices**: Check availability - may need download via Settings

## Common Pitfalls

- **Local variable dies**: Synthesizer gets deallocated if stored locally
- **No voice found**: `AVSpeechSynthesisVoice(identifier:)` returns nil for uninstalled voices
- **SSML parsing fails**: Returns nil if SSML is malformed
- **macOS entitlements**: May need audio entitlement for sandboxed apps
- **Rate values**: Range is 0.0-1.0, not percentage (0.5 is normal speed)

## Code Example: Complete TTS Manager

```swift
import AVFoundation

@MainActor
final class TTSManager: NSObject {
    static let shared = TTSManager()

    private let synthesizer = AVSpeechSynthesizer()
    private var currentUtterance: AVSpeechUtterance?

    var onFinished: (() -> Void)?
    var onProgress: ((NSRange) -> Void)?

    private override init() {
        super.init()
        synthesizer.delegate = self
    }

    func speak(_ text: String, voice: AVSpeechSynthesisVoice? = nil) {
        stop()

        let utterance = AVSpeechUtterance(string: text)
        utterance.voice = voice ?? AVSpeechSynthesisVoice(language: "en-AU")
        utterance.rate = AVSpeechUtteranceDefaultSpeechRate
        utterance.pitchMultiplier = 1.0

        currentUtterance = utterance
        synthesizer.speak(utterance)
    }

    func speakSSML(_ ssml: String, voice: AVSpeechSynthesisVoice? = nil) {
        stop()

        guard let utterance = AVSpeechUtterance(ssmlRepresentation: ssml) else {
            print("Invalid SSML")
            return
        }

        if let voice = voice {
            utterance.voice = voice
        }

        currentUtterance = utterance
        synthesizer.speak(utterance)
    }

    func pause() {
        synthesizer.pauseSpeaking(at: .word)
    }

    func resume() {
        synthesizer.continueSpeaking()
    }

    func stop() {
        synthesizer.stopSpeaking(at: .immediate)
        currentUtterance = nil
    }

    var isSpeaking: Bool { synthesizer.isSpeaking }
    var isPaused: Bool { synthesizer.isPaused }
}

extension TTSManager: AVSpeechSynthesizerDelegate {
    nonisolated func speechSynthesizer(_ synthesizer: AVSpeechSynthesizer,
                                       didFinish utterance: AVSpeechUtterance) {
        Task { @MainActor in
            self.currentUtterance = nil
            self.onFinished?()
        }
    }

    nonisolated func speechSynthesizer(_ synthesizer: AVSpeechSynthesizer,
                                       willSpeakRangeOfSpeechString characterRange: NSRange,
                                       utterance: AVSpeechUtterance) {
        Task { @MainActor in
            self.onProgress?(characterRange)
        }
    }
}
```
